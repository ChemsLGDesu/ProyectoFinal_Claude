# v0.5.0 — Ranked (Milestone 5)

Complete competitive ranked mode with Elo rating, seasonal play, leaderboards, and per-board MMR separation. Series-based fairness solution for 3x3 (solved game). Reuses existing match pipeline; no new game-logic functions.

## Summary of Changes

### Design (game-designer)

[[design-doc]] Section 6 (new) + Section 4 (v3):

- **Elo Rating:** Standard Elo with variable K-factor based on placement phase and MMR tier
  - Initial MMR: 1000 (floor: 500)
  - K = 40 (placement games 0–9), 32 (10–29), 24 (≥30, MMR < 1600), 16 (≥30, MMR ≥ 1600)
  - Per-board separation: mmr3x3, mmr6x6 (future: mmr9x9, mmr11x11)

- **3x3 Series Model:** Single Elo update per 2-game series (players swap first-move roles)
  - Each game reuses normal CreateMatch/PlayMove pipeline
  - Series state: RankedSeriesRecord wraps up to 2 MatchIds
  - Client auto-chains game 2 on empty MatchId after game 1 completes

- **Timers:** 20s per turn (3x3), 30s per turn (6x6); exceed → auto-concede (abandonment)

- **Matchmaking Relaxation:** ±100 (0–9s) → ±200 (10–19s) → ±350 (20–29s) → ±600 (30–44s) → open (45s+)

- **Rewards (Ranked-Specific):**
  - 3x3 series: 10W / 4D / 0L
  - 6x6 match: 15W / 5D / 0L
  - Deliberately lower than Quickmatch to preserve Quickmatch engagement

- **Anti-Boosting:** MMR gain dilution by repeated rival in 24-hour UTC window (1.0 / 1.0 / 0.5 / 0.5 / 0.0); full K for losses/draws

- **Abandonment:** Full K loss for abandoner, full K win for stayer; both abandon = no-contest (ΔMMR = 0)

- **Seasons:** 8 weeks (56 days); soft reset MMR = 1000 + (prev − 1000) × 0.5, floor 500
  - Tiers: bronze [0–899], silver [900–1099], gold [1100–1299], platinum [1300–1499], diamond [1500+]
  - Tier-based seasonal rewards: bronze 100 → diamond 1200 SC + frame; top100 +500 SC + banner

- **Leaderboard:** Raw MMR per board, visible after placement (10 games)
  - Decay: −25 MMR/day above 1200 MMR with 7-day grace period (no decay first 7 days); floor at 1200 and hard floor 500

### Client (gameplay-programmer)

- `RankedQueryService` — GetRankedProfile/GetRankedLeaderboard endpoints; local cache (fallback)
- ModeSelect: "Ranked" enabled; BoardSelect: 3x3/6x6 only
- Series 3x3: game 1 → auto-CreateMatch game 2 → MMR update once (server-side)
- Result screen: MMR delta card per ResultScreenController.cs (does NOT show opponent MMR — see Known Limitations)
- Profile: Ranked tab with MMR, tier, leaderboard rank, season countdown, pending reward badge
- Leaderboard screen (wireframe 10): top N, self entry highlighted, decay indicator
- 20+ new localization keys in UiStrings (all 10 languages)

### Analytics

**5 new events** (must register in Event Manager before emission):
- `ranked_mmr_changed` — Attributes: board_size, mmr_before, mmr_after, delta, k_factor, result, reason
- `ranked_placement_completed` — Attributes: board_size, final_mmr, wins, losses, draws
- `ranked_match_abandoned` — Attributes: board_size, role, turn_index, game_index
- `ranked_queue_fallback_shown` — Attributes: board_size, waited_seconds, choice
- `ranked_season_reward_granted` — Attributes: season, board_size, tier, soft_currency, top100

**3 existing extensions:**
- `match_finished` (online): mode="ranked_3x3" / "ranked_6x6" (fixed from hardcoded "online_quickmatch")
- `matchmaking_wait_time`: mode, mmr_gap (0 if unknown)

### Fixed

- **Analytics mode bug:** match_finished hardcoded "online_quickmatch" for all online matches → now emits actual mode

## Known Limitations

- `ranked_placement_completed`, `ranked_season_reward_granted` not emitted (server defers client data; M5.1+)
- `mmr_gap` always 0 (client does not receive opponent MMR; M5.1+). **Result screen does NOT display opponent MMR.**
- `ranked_match_abandoned` only emits for role stayer/both (privacy reason; acceptable)
- **No series indicator UI** ("Game 1 of 2"); series state managed server-side only
- TTTXO.Game has no unit tests (only TTTXO.Core.Tests); Ranked UI tested manually
- Assets/Triggers/* requires `ugs deploy` CLI; not visible in Deployment window (v1.7.2 limit)

## User Actions (Critical)

1. Install com.unity.services.leaderboards 2.3.4
2. Deploy ranked_3x3.lb and ranked_6x6.lb via `Window → Deployment`
3. Verify UpdateType = Latest score in Dashboard
4. Register 5 Analytics events in Event Manager
5. **Update RANKED_CONFIG.seasonStartUnixSeconds to real UTC timestamp** (placeholder: 1785542400 = 2026-08-01T00:00:00Z)
6. Sync ResetConfig.Start in both .lb with RANKED_CONFIG.seasonStartUnixSeconds
7. Deploy TicTacToeModule.ccmr to Cloud Code
