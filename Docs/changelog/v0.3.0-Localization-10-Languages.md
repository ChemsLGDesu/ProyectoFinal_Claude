# v0.3.0 — Localization (10 Languages)

**Released:** 2026-07-23  
**Status:** Unreleased (internal build)

## Overview

Complete localization support for **10 languages** using Unity Localization (1.5.12). All UI strings translated, language selector active in Settings, and platform-ready for global distribution.

## Key Deliverables

### Unity Localization Setup

**Package:** `com.unity.localization` 1.5.12

**Idempotent Editor Tool**
- Menu: TTTXO → Setup → Create Localization Assets
- One-click generation of localization infrastructure (safe to run repeatedly)
- Creates:
  - 10 Locale assets (en, es, fr, de, pt, it, id, vi, tr, pl)
  - `UiStrings` StringTable (85 keys) with translations for all UI text

**Supported Languages**
| Code | Language | Native Name | Coverage |
|------|----------|-------------|----------|
| en | English | English | 100% |
| es | Spanish | Español | 100% |
| fr | French | Français | 100% |
| de | German | Deutsch | 100% |
| pt | Portuguese | Português | 100% |
| it | Italian | Italiano | 100% |
| id | Indonesian | Bahasa Indonesia | 100% |
| vi | Vietnamese | Tiếng Việt | 100% |
| tr | Turkish | Türkçe | 100% |
| pl | Polish | Polski | 100% |

### UI String Catalog

**85 Localized Keys in `UiStrings` StringTable**

Core screens and actions:
- Screen titles (Home, ModeSelect, BoardSelect, Game, Result, Profile, MatchHistory, Settings, Store)
- Difficulty labels (Easy, Normal, Hard, Adaptive)
- Board size labels (Small/3×3, Medium/6×6, Large/9×9, Gigantic/11×11)
- Mode labels (vs. AI, Local 2P)
- Game states (Your turn, AI thinking, You win, You lose, Draw)
- Actions (Play, Settings, Profile, History, Back, Confirm, Cancel, Delete)
- Player info (Nickname, Wallet, Level, Ranking)
- Notifications (Confirming will delete all data, etc.)
- Store placeholder (Coming soon)

**"Ranked" Terminology**
- English: "Ranked" (full term)
- Spanish: "Clasificado" (translation)
- French: "Classé" (translation)
- Portuguese: "Classificado" (translation)
- Italian: "Classificato" (translation)
- German, Indonesian, Vietnamese, Turkish, Polish: "Ranked" (borrowed term, no suitable native equivalent)
- All variants stored in StringTable for consistency

### Runtime Resolution

**UiText Component** (Updated)
- Resolves strings via `com.unity.localization` API
- Fallback behavior: if string lookup fails → hard fallback to English (never returns null or empty)
- All UI screens protected against missing translations (no broken UX)

**Language Selection & Persistence**
- Settings screen has active language selector
- Displays native language names (e.g., "Español", "Français")
- Player can change language mid-game
- Selection persisted in PlayerPrefs (`TTTXO_Language`)
- Changes apply on-the-fly (no restart required)

### Font Coverage

**Extended Latin Support**
- Font asset includes glyphs for:
  - Base Latin (en, es, fr, pt, it)
  - Extended-A (de, id)
  - Vietnamese diacritics (vi) — **QA TODO:** Verify full coverage
  - Turkish special chars (ğ, ş, ı, ü) (tr) — **QA TODO:** Verify rendering
  - Polish diacritics (ą, ć, ę, ł, ń, ó, ś, ź, ż) (pl) — **QA TODO:** Verify rendering

**Known Gaps**
- Extended Latin font coverage for tr/vi/pl is noted as **QA TODO** in design-doc
- No blocking issue; all 10 languages render at minimum with Latin base + extended-A

### Configuration

**Localization Settings (via Unity Localization)**
- Active locale set to system language on first launch (with fallback to English if unsupported)
- All strings loaded from `UiStrings` table
- No runtime string generation (all 85 keys pre-translated)

### No Gameplay Changes

- All M1 + M2 features intact (AI, rewards, UGS integration, UI)
- Localization is presentation-only; core game logic unchanged
- No balance changes
- No new mechanics

## Testing & QA

- All 85 UI strings translated and tested for fit (no text overflow in 10 languages)

## Editor Tools

**Localization Asset Generator (Idempotent)**

```
TTTXO/Setup/Create Localization Assets
├── Validates existing locales (skips if already present)
├── Creates StringTable with 85 keys
├── Applies translations from CSV/database
└── Logs summary (e.g., "Created 10 locales, 85 strings")
```

Running multiple times is safe; duplicate creation is prevented.
