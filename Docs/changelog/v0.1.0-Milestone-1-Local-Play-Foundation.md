# Milestone 1 — Local Play Foundation | v0.1.0

**Released:** 2026-07-23  
**Status:** Unreleased (internal build)

## Overview

Completion of **Milestone 1: Local Play Foundation** — a fully functional tic-tac-toe game with AI, four board sizes, multiple difficulty levels, and local multiplayer support. Core gameplay loop implemented and validated through extensive test coverage.

## Key Deliverables

### Design Documentation
- [[design-doc]] — Complete M1 specification including board configurations, local play rules, AI difficulty cascades, and soft currency reward system

### Game Design
- [[02-GDD-TicTacToe]] — Game design document with mechanical overview
- [[03-Arquitectura-UGS-TicTacToe]] — Architecture reference (UGS integration planned for future)

### Core Systems
**Pure C# Assembly (TTTXO.Core)**
- Board representation, state validation, and move mechanics (MatchController, BoardState, RulesEngine)
- k-in-a-line victory detection with overline support
- AI player engine: cascading strategy (win → block → positional) with alpha-beta minimax
- Difficulty parameters (Easy/Medium/Hard/Adaptive) with 10-game adaptive window
- Reward calculator for soft currency (10–40 base per board size, 0.5–1.5× multipliers by difficulty)
- **75 EditMode tests, all passing** (50+ Hard-3×3 vs random without defeat)

**Unity UI Layer (UI Toolkit)**
- Screen router and 6 core screens (Splash → Home → ModeSelect → BoardSelect → Game → Result)
- Dark theme with neon accent palette
- Centralized UI text (localization ready)
- Dynamic board rendering in C#

**Game Systems**
- GameManager: first-player alternation, adaptive AI per board size, soft wallet persistence
- AppBootstrap: scene initialization (idempotent Main.unity setup)
- Background thread AI with 400ms move delay for UX responsiveness

## Configuration & Balance

### Board Sizes
| Size | k-value | Reward Base |
|------|---------|-------------|
| 3×3  | k=3     | 10 coins    |
| 6×6  | k=4     | 20 coins    |
| 9×9  | k=5     | 30 coins    |
| 11×11| k=5     | 40 coins    |

### AI Difficulty Cascade
- **Easy:** pWin 0.70, pBlock 0.50
- **Medium:** pWin 1.0, pBlock 0.9, blunder 0.25
- **Hard:** Minimax depth 4, unbeatable on 3×3, blunder 0.05 on 6×6+
- **Adaptive:** Levels 0–100, 10-game rolling window, target win rate 0.40–0.60

### Soft Currency Limits
- Daily win cap: 20 coins
- Global daily cap: 300 coins
- Local 2-player flat multiplier: ×2

## Rules

- Victory: k consecutive symbols in any direction
- Overline: Allowed (lines longer than k do not invalidate)
- Draw: Only on full board (no early surrenders)
- Turn timer: None in M1

## Testing

- **EditMode Test Suite:** 75 tests across 6 files (RulesEngine, MatchController, BoardConfig, AiPlayer, AdaptiveAiController, RewardCalculator)
- **Validation:** 50+ Hard-3×3 matches vs random without AI defeat
- **Note:** Batch-mode test execution blocked by editor lock; run via Window → General → Test Runner

## Environment

- Unity 6000.3.20f1
- .NET Framework (C# 12)
- Targeted for standalone builds (WebGL planned for M2)

## Known Limitations (Future Milestones)

- No turn timer (M2+)
- No network play (M2+)
- No analytics or telemetry (M2+)
- Soft currency caps are client-side only; server-side enforcement planned (M2+)
